What you get

    
Seven segments, color-coded by severity.

Caveman badge

🤖 Claude Sonnet 4.6
Model
Which model is answering right now.

      
CTX ████░░░░ 42%
Context window
Usage bar going green → yellow → red.

      
⚡ ▄ MEDIUM
Effort level
Shown only when the model supports it.

      
5h ████░░░░ 42% used · 58% rem ↺ 1h 22m
5-hour limit
Spent, remaining, and time until reset.

Weekly limit
Both values colored independently by severity.

Install

    
Needs Claude Code, Node.js LTS, and bash (Git for Windows or WSL on Windows).

    

      
      
    

    
git clone https://github.com/FahimFBA/claudecode-statusline.git
cd claudecode-statusline
chmod +x install.sh
./install.sh

    
git clone https://github.com/FahimFBA/claudecode-statusline.git
cd claudecode-statusline
powershell -ExecutionPolicy Bypass -File install.ps1

    
Then restart Claude Code. Choose 1) Full install or 2) Custom to pick components.


    
What the installer does

    
    
      
  1. Copies hook scriptsInto ~/.claude/hooks/.
    2. 
      
  2. Merges settingsInto ~/.claude/settings.json — existing file is backed up first, other config survives.
    3. 
      
  3. Installs the Caveman pluginVia claude plugins install caveman --marketplace caveman.
    4. 
    

  






  

    
Customize

    
Re-run the installer and pick option 2, or set env vars in the statusLine command.

    

      

        
Env varDefaultHides

        
          
SL_CAVEMAN=0onCaveman badge

          
SL_PROJECT=0onProject + branch

          
SL_MODEL=0onModel name

          
SL_CTX=0onContext window bar

          
SL_EFFORT=0onEffort level

          
SL_5H=0onHourly rate limit

          
SL_7D=0onWeekly rate limit

          
SL_SAVINGS=0onToken savings

        
      

    

    
Default Caveman mode:

    
export CAVEMAN_DEFAULT_MODE=lite   # lite | full | ultra | off

# or ~/.config/caveman/config.json
{ "defaultMode": "lite" }

  






  

    
Caveman mode

    
Terse replies, same technical substance. Powered by JuliusBrussee/caveman.

    

      

        
CommandEffect

        
          
/cavemanActivate full mode

          
/caveman liteFewer drops

          
/caveman ultraMax compression

          
/caveman offDeactivate

          
/caveman-statsSession usage + savings

          
/caveman-stats --allLifetime stats

        
      

      

        
LevelBehaviour

        
          
liteDrop articles and filler, keep sentence structure

          
fullFragments OK, short synonyms

          
ultraMinimal connectives

        
      

    


    
Uninstall

    
rm ~/.claude/hooks/caveman-*.js ~/.claude/hooks/caveman-statusline.sh

    
Then remove the hooks, statusLine, enabledPlugins and extraKnownMarketplaces keys from ~/.claude/settings.json.
